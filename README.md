
# Blockchain Technology Used in Smart Drug Supply with QR Code Verification

## Project Description
This project demonstrates the use of blockchain technology and QR codes to record and verify drug supply information.

## Objectives
- Maintain drug batch records.
- Link records using cryptographic hashes.
- Generate QR codes for drug batch verification.
- Check the integrity of recorded information.

## Technologies Used
- Python
- Flask
- SHA-256
- QR Code

## Features
- Blockchain record creation
- Drug batch tracking
- QR code generation
- Batch verification

## How to Run
1. Install Python.
2. Install dependencies:
   py -m pip install -r requirements.txt
3. Start the application:
   py app.py
4. Open http://127.0.0.1:5000 in your browser.

## Disclaimer
This is an academic prototype. It does not independently establish the authenticity or safety of medicines.
